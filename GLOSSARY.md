# KVC Consultation Intake

Terms used to identify the owner of consultation requests submitted through the website.

## Language

**Consultation request**:
Information submitted by a person asking KVC to contact them for advice. A request does not establish that the person has received advice or become a customer.
_Avoid_: Advised customer

**Link-attributed owner**:
The staff member identified by the most recent valid referral link within the same browsing session. This assignment does not establish that the staff member has provided advice.
_Avoid_: Verified adviser

**Valid staff code**:
A referral code belonging to a staff member currently authorized to receive consultation requests. An invalid code does not replace a valid code already recorded during the browsing session.
_Avoid_: Arbitrary staff code

**Default intake owner**:
The person or team responsible for a consultation request when no link-attributed owner has been identified.
_Avoid_: Guessed owner

**Lead**:
A person whose interest in consultation has been recorded for KVC to assess and follow up. A lead is not necessarily a paying customer.
_Avoid_: Paying customer

**Browsing session**:
A visit within the same browser tab, including page navigation and reloads, ending when the tab is closed. Independent tabs may have different link-attributed owners.
_Avoid_: Long-term referral history
